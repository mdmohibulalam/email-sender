# Third-party components

Campaign Studio uses Microsoft .NET/ASP.NET Core, Windows App SDK/WinUI, WebView2, Entity Framework Core, Npgsql, SQLite/SQLitePCLRaw, MailKit/MimeKit, and their transitive dependencies. Their original licenses and attribution requirements continue to apply.

Package references pin the source dependencies. The portable build includes runtime license and third-party notice files copied from the .NET distribution. Check the original NuGet package metadata and Microsoft WebView2 distribution terms when assembling a commercial installer.

This project contains three original simple email layouts. No SendBlaster code, templates, icons, branding, or assets were copied. No font or UI framework is downloaded at runtime; the interface uses system fonts and bundled CSS/JavaScript.
